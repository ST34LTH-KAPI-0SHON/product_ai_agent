# Пользовательские проекты

Один каталог — одна задача руководителя продукта. Целевая структура описана в [архитектуре](../docs/ARCHITECTURE.md). Сейчас демонстрационного проекта и подтверждённых продуктовых фактов здесь нет.

Рабочие данные по умолчанию держите в `local-<name>/`, который исключён из Git. Будущий `init` должен создавать структуру без перезаписи. Для публикации демонстрационного проекта отдельно проверьте права использования и отсутствие персональных данных во всех файлах, включая реестры, checkpoints и отчёты.

`.gitignore` не является системой защиты персональных данных. Результаты также могут содержать чувствительные сведения. Разрешённые публичные демо-материалы можно явно добавить в Git после ревью; запрет на закрытые данные этим не отменяется.

Новый чат должен читать состояние и исходные основания, а не только последний текст стратегии. Ответ агента не становится фактом из-за сохранения на диск.
