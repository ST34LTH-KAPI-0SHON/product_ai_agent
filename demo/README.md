# Готовый демонстрационный проект

[Открыть карточку решения](decision.html) · [Короткий вывод](decision.md) · [Полная папка исследования](confirmed-run.zip)

Сохранённый пользовательский прогон «Командный ритм»: описание продукта, таблица и заметки (синтетические), разрешённая настоящая страница, два расчёта, четыре альтернативы, реальный выбор пользователя, стратегии и продолжение в новом чате. Карточка версии 0.2 добавлена поверх проверенного результата без изменения исходного пользовательского исследования.

В confirmed-run.zip находятся исходные материалы, снимки, локаторы, расчёты, реестры, checkpoints и состояние. Сайт - внешний источник с сохранённой атрибуцией; его заявления относятся только к альтернативе. Учебные сведения не доказывают реальный спрос. Архив не содержит .venv, секретов или машинных заметок ремонта ACL.

Чтобы продолжить пример, попросите агента: «Восстанови готовый пример через demo/restore.py, затем покажи принятое решение и открытые вопросы». Скрипт создаёт новый каталог и не обнуляет существующие исследования.

Второй кейс с иным вопросом и метриками - [онлайн-запись](../examples/booking/README.md). Его выбор пользователя ещё не получен, поэтому итоговая стратегия от его имени не утверждалась.
