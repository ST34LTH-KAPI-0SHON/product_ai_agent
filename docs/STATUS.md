Локальная запись восстановления — drafts/file-access-repair.json. Первый Set-Acl потребовал недоступный SeSecurityPrivilege; применено изменение только секции Access через DirectorySecurity, без изменения owner/SACL. Запрос открытия через open_in_codex принят со статусом queued; фактическое отображение в интерфейсе не наблюдалось. Остаток — проверить открытие пользователем; исследование повторно не запускать.
