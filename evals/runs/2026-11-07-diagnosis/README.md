# Сравнение: диагностика экспорта

Одинаковый вопрос и три текстовых материала из examples/export-diagnosis переданы обычному чату и агенту в отдельных контекстах. Все данные синтетические. Сначала был получен нетаймированный пробный ответ; затем сохранены измеренный ответ чата и новый агентный прогон. Оба ответа чата опубликованы, отбор по выгодности не выполнялся.

| Наблюдение | Обычный чат | Агент |
|---|---|---|
| Измеренное время | 42 с | 420 с |
| Область | Текстовый ответ, чтение входов и запись результата | Исследовательские документы, источники и 14 утверждений, самопроверка, пауза/восстановление, HTML и переносимый архив |
| Ошибки инструментов исследования | Не применимо | 0 ошибок CLI; 2 ошибки поиска/чтения путей раскрыты |
| Измеренная стоимость / точный ID модели | Неизвестны | Неизвестны |
| Содержательная оценка | Полезный достаточный ответ для короткой диагностики | Сходные основные выводы, более явно разобран риск навязанной исследованием проблемы |

Преимущество в скорости или универсальном качестве не установлено. Для разового короткого ответа обычный чат оказался быстрее и достаточен. Пакет агента полезен, когда нужны сохранённые основания, проверяемые версии и дальнейшая работа; эти возможности требуют дополнительного времени.

Новая задача восстановлена отдельным процессом Python, не отдельным LLM-чатом. Код и инструкции стабилизировались параллельно прогону, что ограничивает сопоставимость времени. Независимая проверка новой установки выполняется отдельно и не входит в 420 с. Негативные случаи устаревания ревью проверены автоматическими тестами; LLM-рецензент их не воспроизводил.
