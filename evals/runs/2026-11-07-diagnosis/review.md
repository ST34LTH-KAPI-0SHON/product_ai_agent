# Сравнение двух сохранённых результатов

Это рецензия ещё одной LLM, а не независимая человеческая или слепая оценка. Проверены фактические тексты по семи критериям `evals/benchmark-protocol.md`; длина, число разделов и наличие самопроверки сами по себе не считаются качеством.

Указатели: **B** — `evals/runs/2026-11-07-diagnosis/baseline-timed.md`; **D**, **A**, **V**, **Q**, **S** — соответственно `decision.md`, `analysis.md`, `validation-plan.md`, `quality-review.json`, `run-summary.md` в `projects/local-export-diagnosis-030/reports/`. Номера ниже — строки сохранённых файлов. Полные D/A/V/Q/S, реестры и извлечённые материалы опубликованы внутри examples/export-diagnosis/saved-run.zip; локальный projects-каталог в Git не публикуется.

**Свойства процесса оцениваются отдельно.** В агентном пакете есть реестр источников с происхождением и путями снимков, извлечённые основания, claims и отдельный протокол. У обычного текстового ответа такого пакета нет; это не свидетельство неспособности чата подготовить его по дополнительной просьбе. S:5 сообщает о pause/session в отдельном процессе Python и продолжении сохранённого состояния. Это описание восстановления состояния CLI, не демонстрация продолжения рассуждения новой LLM без истории чата. Q:4 содержит отпечаток предмета ревью, а D:44 и S:19 описывают проверку свежести. По разрешённым здесь файлам автоматическое отклонение действительно устаревшего ревью не проверено: изменение предмета и результат отказа не представлены. Значения `pass` в Q — самооценки агента, не результаты этого сравнения.

**Ограничения.** Один синтетический кейс не проверяет реальный спрос или переносимость результата. Протокол появился после одного нетаймированного пробного ответа, до завершения агентного исследования; предварительной регистрации не было. Итоговые времена, переданные для сравнения: обычный чат — **42 секунды**, агент — **420 секунд**. Это разный объём работы: текстовый ответ против сохранённого исследовательского пакета с источниками, самопроверкой, паузой и продолжением. Указанные в S:15 316 секунд — промежуточный срез, не итог. Точные ID моделей, токены и денежная стоимость обоих вариантов неизвестны; оценивать экономическую эффективность нельзя. Ревью не запускало продуктовый CLI, модели, веб или исследования с людьми и не перепроверяло код механизма свежести.

**Практический результат.** Для исходного запроса короткой диагностики обычный чат даёт достаточный осторожный ответ и получен быстрее. Агент подробнее разбирает риск самой проверки и сохраняет удобные основания для продолжения работы; пакет при этом заметно объёмнее запрошенной короткой диагностики. Этот пример показывает пользу сохранённого процесса, но не устанавливает общего превосходства агентного анализа над сильным обычным ответом. Причина реальной невостребованности остаётся неизвестной в обоих результатах.
