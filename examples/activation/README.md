# Учебный кейс «Командный ритм»

Все продуктовые сведения, заметки и числа в этой папке синтетические. Они проверяют инструменты и исследовательский процесс, не доказывают реальный спрос.

Вопрос: почему снизилась семидневная активация и куда направить ограниченный ресурс команды — оставить процесс, улучшить текущий продукт, сменить направление или закрыть его?

Подготовка проекта из корня репозитория:

```powershell
python examples/activation/prepare.py --project projects/local-activation
```

Скрипт только создаёт проект и копирует учебные входы/спецификации. Он не проводит исследование, не генерирует выводы и не записывает человеческий выбор.

Затем в агентной среде: «Прочитай instructions/entry.md. Проведи исследование projects/local-activation по запросу из inputs/request.md. Используй CLI и сохраняй состояние. При существенном выборе дождись моего ответа».

Веб закрыт по умолчанию. Для примера сопоставления позиционирования можно явно разрешить `https://basecamp.com/` через configure, когда страница доступна. Её заявления относятся к Basecamp; переносить их на учебный продукт нельзя. Разрешение других URL/редиректов требует явного изменения политики разработчиком/пользователем.
