# Учебный продукт «Итоги встречи»

Все сведения ниже синтетические и предназначены только для проверки агента.

## Задача и возможности

Сервис помогает руководителю команды согласовать итоги встречи. Черновик отчёта доступен для просмотра и обсуждения по ссылке. После подтверждения владельцем отчёт получает статус «Утверждён».

Экспорт доступен только для утверждённого отчёта: меню «Ещё» → «Сохранить копию». Поддерживается HTML-файл. Для черновика пункт меню скрыт. CSV, XLSX и PDF не поддерживаются.

## Коммуникация

На странице продукта написано: «Согласуйте итоги встречи и поделитесь готовым отчётом с командой». В этой фразе не названы формат экспорта и ограничение по статусу отчёта.

## Доступные данные

Есть восемь учебных реплик. Нет событий просмотра меню, числа утверждённых отчётов, числа пользователей, частоты экспорта, данных о сегментах, оплате или стоимости разработки. Нельзя вычислить конверсию или распространённость потребности по этим репликам.
