# Второй учебный кейс: аудитория платного предложения

Вопрос: «Кому сначала предложить платный продукт онлайн-записи и каким сообщением?». Все продуктовые сведения синтетические. Кейс отличается от падения активации: выбор аудитории, конверсия пробных команд и нагрузка поддержки.

Агент читает product.md и metrics.csv, считает paid/trials и support_tickets/trials по сегментам, учитывает маленькую выборку network и ограничения функций. Нельзя выдавать максимальную долю за доказательство выгодности сегмента. Стратегический выбор подтверждает пользователь.

Этот кейс прошёл инструментальный и исследовательский путь до рекомендации/ожидания выбора. Реального подтверждения направления и эксперимента нет. Результат — проверка переносимости подхода, не оценка рынка.
