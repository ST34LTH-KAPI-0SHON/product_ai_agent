# Материалы для вашей задачи

Сюда можно положить разрешённые документы Markdown/TXT/DOCX и таблицы CSV/XLSX. Затем в чате скажите: «Используй материалы из inbox для моей задачи …». Только после этого агент копирует их в отдельное исследование. Файлы не публикуются в Git.

Не помещайте сюда ключи, пароли, закрытые корпоративные данные и персональные данные без разрешения. Доступные сайты задаются явными ссылками в запросе.
