# Протокол выполнения

Проект / сессия / дата / версия кода:

- Среда и модель, способ доступа:
- Начало, конец, часовой пояс, длительность:
- Какие этапы реально завершены:
- Существенные действия и выбранные проверки:
- Прочитанные источники и результаты инструментов:
- Ошибки, повторы и их влияние:
- Помощь человека и затраченное время:
- Что остановлено или осталось неизвестным:
- Где сохранены состояние, итог и основания:

## Расходы

| Компонент | Фактическое/оценочное значение | Валюта/единица | Источник измерения/метод оценки | Ограничения |
|---|---|---|---|---|
| Модель/среда | Неизвестно | | | Не заменять неизвестное нулём |
| Поиск/сеть/платные инструменты | Неизвестно | | | |
| Повторы/доработка | Неизвестно | | | Не считать дважды |
| Работа человека | Неизвестно | Минуты | | |

Полная денежная стоимость при оценке времени человека требует явно указанной ставки. Подписка и предельная стоимость одного прогона — разные величины; описать метод распределения, если он применялся.

## Продолжение
